# L'Île de Mimi

A gentle, no-danger 2.5D isometric tropical island game built for **Mimi**—focused on exploration, discovering fascinating flora and friendly fauna, building a cozy camp, and enjoying sunny days, gentle rain, and starry nights.

Designed as a mobile-first **Progressive Web App (PWA)** for Android phones and PC laptops.
